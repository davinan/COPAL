# Vendored RALPH source

This directory was originally a snapshot of
<https://github.com/davinan/ralph> at commit `92b226a`, imported into this
publication repository on 2026-04-23.

COPAL integration changes maintain database loading and notebook visualization.
The query-ranking wrapper shares hit filtering between the notebook and benchmark CLI.
The `aggregate_rankings` calculation remains unchanged from the original snapshot.

Upstream fixes should be synchronized explicitly rather than silently replacing
these integration changes.
